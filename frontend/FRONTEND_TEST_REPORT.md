# EvidenceOps 前端验收报告

验收日期：2026-10-15。浏览器为 Microsoft Edge；产品为 Next.js 16 / React 19 前端。本报告记录实际执行结果，不把后端组的测试数量计入本次结果。

## 验收环境与数据边界

正式安装使用 3013/8014、原安装数据目录和 PostgreSQL。正式历史仅执行 GET 查询与页面回放，不新增诊断，不改变模型默认连接，不恢复或覆盖正式数据库。快照兼容检查遍历 41 条 Run，覆盖 20 条成功、20 条失败、1 条取消；归档接口共返回 31 条终止事件，未对其余记录补造事件。

会产生写入的浏览器用例使用独立的 3011/8011 诊断服务和 3015/8016 安装服务，数据位于 `output/playwright/audit-20261015/`。供应商调用使用确定性替身或 Mock，不使用真实付费模型。浏览器测试返回 `passed=true` 才计为通过，不能仅依据命令退出码。

## 修复及防护

| 问题 | 处理和验证 |
| --- | --- |
| 验收快照只有 provider/model_id，整份历史因缺连接字段无法读取 | 支持两种供应商字段及可空追溯字段，未知信息显示未记录；保持已提供字段的类型检查；真实截图 Run 和全量历史回放通过 |
| 未读到运行结果却显示诊断中和取消按钮 | 只有结果或 run_started 证明运行状态后才展示执行状态；未确认时显示正在读取或状态未确认，不提供未经确认的取消动作 |
| Zod 字段错误和内部数据直接显示给用户 | 运行、列表及评测异常转换为可处理文案；损坏响应保留恢复入口，统计校验保留具体业务错误 |
| 历史结果没有独立核验请求身份，最终 GET 后缺少过期检查 | 初始及最终响应都核对 run_id，最终解析后再核对请求代次及取消信号；恢复时立即使用已确认结果 |
| 终止事件名称与结果状态冲突缺乏校验 | 明确核对 completed/succeeded、failed/failed、cancelled/cancelled，不接受冲突终态 |
| 新历史观察继承上次自动重试次数和取消等待标记 | 切换档案时重置两者，避免旧操作影响新观察 |
| 历史列表缺乏响应格式校验和直接重试 | 校验列表结构，格式异常不显示空列表或分页；增加重试；筛选无结果与没有档案分别表达 |
| 知识抽屉的检索标识过长，重要信息被挤到后面 | 原文保持纯文本展示，检索标识折叠到追溯详情，运行摘要和版本保持可查；窄屏及键盘关闭测试通过 |
| 旧式 Mock 快照未识别演示标记 | provider 和 provider_id 两种快照均保留明确演示提示，不能展示成真实故障结论 |
| 验收脚本之间遗留请求拦截 | 运行器每组开始前清理拦截；修复输入安全脚本依赖不可用的 process 全局变量，复跑通过 |

## 复现与证据

- `frontend/tests/run_browser_audit.py`：12 组 CLI 浏览器运行器；首次安装组需要全新隔离目录。已安装目录仅回归指定组，不能指向正式服务执行恢复测试。
- `frontend/tests/audit-history.ts`：只读遍历实际安装的历史及归档事件；从 frontend 执行 `npx.cmd tsx tests/audit-history.ts`。
- `frontend/tests/browser-history-compatibility.js`：只读浏览器遍历真实历史，可在 3011 新版测试前端或 3013 生产前端运行。真实历史服务固定为本机 3013。
- `frontend/tests/browser-run-resilience.js`、`run-compatibility.test.ts`：响应损坏、状态/身份不一致及两种快照兼容回归。
- `output/playwright/audit-results/results.json` 和同目录日志：12 组结果及断言记录。
- `output/playwright/audit-20261015/real-history.log`：更新后的测试前端对真实历史逐条回放结果。
- `output/playwright/audit-20261015/production-history.log`：重新构建并启动后的 3013 生产网页，41 条真实历史逐条回放通过。
- `output/playwright/real-knowledge-history.png`：实际归档知识片段截图。
- `output/playwright/audit-*-320.png`、`audit-*-1440.png`：五页窄屏和桌面截图。
