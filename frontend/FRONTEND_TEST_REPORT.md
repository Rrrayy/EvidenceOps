## 输入边界补充验收

原验收遗漏了纯问号提交和固定 Mock 报告的真实性提示。补充修复后，输入框、诊断代理及后端同步／流式接口拒绝空白、纯标点、纯符号及超长描述；`OOM`、`404`、中文短故障和多语言日志仍允许提交。这是结构校验，不代表已经确认描述具有充分的故障语义。

报告按运行快照的 `provider_id=mock` 显示“Mock 演示报告”、固定样例说明及“样例置信度”；不依据后来修改的默认连接改写历史标识。缺少快照的旧记录不推断模型来源。

- 相关后端回归：69 项通过；覆盖无效请求不进入诊断执行、不调用模型及不创建运行。
- 前端单元测试：15 项通过；生产构建和 TypeScript 检查通过。
- 实际 3013／8014 浏览器复查：问号、全角问号、省略号及纯表情均禁用提交，快捷键不发请求、不清空输入；代理及两个后端入口返回 422，历史列表保持不变。
- 已有 Mock 历史报告的演示标识与样例置信度展示通过。未执行有效生产诊断，未调用付费模型，未修改连接或默认值。
- 复查脚本：`frontend/tests/browser-input-safety.js`，默认使用隔离的 3011／8011，可通过 `EVIDENCEOPS_TEST_WEB_URL`、`EVIDENCEOPS_TEST_API_URL` 设置测试地址。脚本读取已有历史寻找 Mock 报告，不创建运行；没有对应报告时明确标记演示标识未验收，不假报通过。

| B04 | 存储维护失败后，保留的配置草稿失去关闭确认 | 失败后恢复未提交标记 | 拒绝放弃时保留抽屉、确认后关闭 |

| B07 | 极窄屏历史表格把运行 ID 挤成逐字竖排，记录行异常高 | 历史表格设置最小宽度，在容器内部滚动 | 窄屏记录行高检查及截图复查 |

| B09 | 已完成的历史诊断加载事件时仍显示取消按钮 | 取消入口同时检查业务状态，历史加载不等于任务运行 | 阻塞历史事件请求时，完成报告不出现取消入口；活跃 Run 仍可取消 |

## 尚未验收的范围

- 未进行真实付费千问供应商的重复调用、限流或长时间压力测试；Mock 验证不代表真实模型回答质量。
- 未实测 Firefox、Safari、真实手机浏览器或屏幕阅读器；当前为 Edge 自动化及移动视口测试。
- 未做大型客户数据库、接近 100 MB 备份、多日运行、断电和磁盘耗尽等现场试验。本次包含相关已实现后端单元测试，不替代现场验收。
- 客户日志数据源接入、多人权限、自动备份和自动历史清理尚未作为产品能力开放，不计为已通过功能。
- 浏览器中有预期的故障注入 4xx/5xx 及开发 API 不支持安装状态的 404；与 JavaScript 运行异常分别核对，不能笼统宣称所有控制台消息为零。
